# MentorLink — Frontend (client)\n\nThis folder contains a Vite + React frontend scaffold for MentorLink.\n\nQuick start:\n1. cd client\n2. npm install\n3. npm run dev\n\nNotes:\n- Tailwind + DaisyUI are configured. Edit tailwind.config.js to tweak theme tokens.\n- Auth is stubbed in src/context/AuthContext.jsx — integrate with your backend.\n- Socket.io client is in src/utils/socket.js — set VITE_SOCKET_URL to connect to real socket server.\n- This is a starter scaffold with role-based routes and sample components. Extend pages and connect APIs as needed.
